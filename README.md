# Nodoro
Pomodoro timer for Android with Nothing Phone Glyph support (Material 3 Expressive).
This is the open build: every feature is unlocked, there are no ads, no purchases, and the app does not request
the Internet permission.
```
./gradlew assembleRelease
```
Release signing: create `keystore.properties` (git-ignored) with `storeFile`, `storePassword`, `keyAlias`, `keyPassword`.
